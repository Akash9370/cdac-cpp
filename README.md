# cdac-cpp — CDAC PGCP-AC (C++ module) Assignments — 2026

This repository contains my assignments and practice programs for the CDAC PGCP-AC course (C++ module), batch 2026. Each folder (day1, day2, ...) contains the examples and small programs done during that day's lab/class. The code is intended for learning and demonstration.

## Contents (brief)
- day1  
  - Basic language features and small exercises: 1D arrays, string handling, `sizeof`, `static` variables, constant pointers/variables, `extern` functions, and menu-driven loops. Simple examples to practice fundamentals of C/C++ syntax and memory usage.

- day2  
  - Collection of day-2 assignments and student examples. Contains early practice problems that build on control flow, functions, and basic I/O.

- day3  
  - Collection of day-3 assignments and student examples. Reinforces arrays, loops, simple algorithms and introductory problem solving.

- day4  
  - Collection of day-4 assignments and student examples. Typical topics include functions, modular code organization and more practice problems expanding on earlier concepts.

- day5  
  - Collection of day-5 assignments and student examples. Usually covers intermediate topics and small algorithmic problems (sorting, searching, small utilities).

- day6  
  - Examples and assignments (includes an `address` folder). Focus on structured data (structs/classes), string and record handling, and related exercises.

- day8  
  - Collection of day-8 assignments and student examples. Continued practice and consolidation of previously introduced concepts.

- vehicle  
  - OOP examples: Vehicle, Car, Bike classes and a Test program. Demonstrates class design, header/source separation, inheritance and polymorphism basics.

## Notes
- Each day-folder may contain zipped submissions or per-student directories — browse inside the folder for individual programs.
- Most programs are single-file examples; compile with a modern g++/clang++ (C++17 or newer) using:
  - g++ -std=c++17 -O2 -Wall path/to/file.cpp -o bin/program
